## Goal

Find out what a fresh deploy of tts really does today, before changing anything. No code is changed in this group: each leaf writes what it found in its *Notes*, and anything that contradicts [../../../deployment_audit/tts.md](../../../deployment_audit/tts.md) or the documents is corrected there (T-04).

## Why before the fixes

The working folder already holds the voice (`models/`, F11), a populated venv and uncommitted documents, so it proves nothing about a fresh machine. A clean clone and the deployment tool prove the path a real deploy takes.
