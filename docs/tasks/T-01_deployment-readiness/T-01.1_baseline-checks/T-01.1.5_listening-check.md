## Goal

A person listens to the Piper voice with the droid effect (and the `espeak` robot voice) and judges the sound. Nobody has done this: the effect values were tuned on paper and by tests (debt D-2, requirement FR-14).

## Steps

1. `windows\Scripts\python.exe scripts\render_samples.py`.
2. The maintainer plays the files in `models/samples/` and says which variant is right, or which values to change.
3. Only if the maintainer chooses new values: change the defaults in `tts_config.py` and `.env.example`, the table of `README.md` and [../../../configuration/environment-variables.md](../../../configuration/environment-variables.md), run `env_inventory.py --write`, and update the tests that pin the old defaults.

## Acceptance criteria

The maintainer's judgement is in *Notes* (which file, which values, or "keep"). D-2 and FR-14 are updated to `Resolved` / `Done` only if the maintainer says the sound is accepted.
